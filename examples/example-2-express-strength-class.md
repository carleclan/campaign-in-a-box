# Example 2 — "Express Strength" class launch

**Persona:** Time-Poor Professional · **Goal:** fill a new 45-min class · **Deliverable:** full kit

---

## INPUT — the brief

```text
CAMPAIGN BRIEF
- Campaign name: Express Strength launch
- Goal: fill the new 6:30am + 12:15pm classes (16 spots each) within a month
- Target persona: Time-Poor Professional
- The one action we want them to take: reserve a spot in an Express class this week
- Offer or hook: 45-minute full-body strength session that fits a lunch break
- Key dates: classes start Mon; bookable in the app
- Must-include details: 45 min, coached, all levels; book in the Forge app
- Deliverables: the full kit
- Anything to avoid this time: don't imply it's "easy" — it's efficient, not soft
```

---

## OUTPUT — the plan

- **Goal:** fill two new Express Strength classes (32 spots) within a month.
- **Persona & action:** Time-Poor Professional → reserve a spot this week in the app.
- **Angle:** "45 minutes, fully coached, done. Fits the gap you already have."
  Sell time-efficiency and structure, not ease.
- **Deliverables:** 3 social posts, 1 email, 1 paid ad, 1 flyer concept.
